Paper A — “Hairline” · session screen

Full-screen, keyboard-exclusive overlay on the focused screen, GlobalStates.sessionOpen. The scrim is paper at 92 % (dusk paper at 92 % in dark mode) — near-opaque, so the six choices sit on a clean page. Clicking the scrim cancels. ←/→/↑/↓/Tab move, Home/End jump, Enter or Space runs, 1–6 select and run immediately, Escape cancels; hover also moves the selection.

Type: the shell sets body/UI in Inter (google-inter-fonts / ttf-inter) and every numeral, identifier and path in JetBrains Mono (already installed here). These pages fall back to Adwaita Sans — an Inter derivative — when Inter is absent, so shapes are within a hair of the real thing; all sizes, weights, tracking, colours and metrics are the real values.

The six 132 × 132 bordered tiles are gone. Each action is a column of accelerator, 28 px glyph and micro-cap label, and the columns are separated by 1 px vertical rules that run the full height of the row — the only vertical rules in the theme apart from the bar dividers. The selected column takes ink on the glyph and label plus a 1 px underline; the accelerator lifts from ink-4 to ink-2. Nothing inverts, nothing fills.
