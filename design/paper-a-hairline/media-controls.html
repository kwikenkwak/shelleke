Paper A — “Hairline” · media controls

Anchored top-left, barHeight + 8 = 46 px down, flush with the left edge, 480 px wide. The layer surface keeps a fixed height so it never resizes; only the inner card animates between 168 px and 392 px over 280 ms as the lyrics open. Masked to the card, focus-grab + Escape to close.

Type: the shell sets body/UI in Inter (google-inter-fonts / ttf-inter) and every numeral, identifier and path in JetBrains Mono (already installed here). These pages fall back to Adwaita Sans — an Inter derivative — when Inter is absent, so shapes are within a hair of the real thing; all sizes, weights, tracking, colours and metrics are the real values.
