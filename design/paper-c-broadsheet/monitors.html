Paper C — Broadsheet: displays overlay

380 px docked to the left edge — a GUI over hyprdynamicmonitors. Three screens: the main page (quick layout, arrangement, primary, zoom, connected outputs, profiles), the profile editor and the settings page. Every write still goes through the Monitors service.

Fonts. Display / titles / numerals: TeX Gyre Pagella (Palatino lineage; real smcp small caps, onum oldstyle and tnum tabular figures) — installed here, so these previews show the actual face. Data / labels: Lato. Tabular micro-data, paths and logs: Source Code Pro. All three are libre and packaged on Fedora; the shell bundles them in assets/fonts/ exactly as the pixel family bundles its bitmap faces.

Every screen in this panel shares one masthead: an optional back chevron, a Pagella small-caps title, the actions on the right, then the Oxford rule. Below it the page is a run of small-caps section heads, each closing its own hairline. The daemon state, the mirroring flag and anything else binary is a stamp; anything proportional (zoom steps) is a chip row, with impossible steps set as dotted disabled chips rather than dimmed ones.
