Paper C — Broadsheet: widget catalog

The shared vocabulary every surface is assembled from — the paper answer to PixButton, PixPanel, PixField, PixIcon, PixText, PixTitle, PixTooltip, PixToggleTile, PixBatteryGlyph and PixAppIcon. Each widget is shown in every state it can hold.

Fonts. Display / titles / numerals: TeX Gyre Pagella (Palatino lineage; real smcp small caps, onum oldstyle and tnum tabular figures) — installed here, so these previews show the actual face. Data / labels: Lato. Tabular micro-data, paths and logs: Source Code Pro. All three are libre and packaged on Fedora; the shell bundles them in assets/fonts/ exactly as the pixel family bundles its bitmap faces.

One control, five voices. Rest is a hairline on a paper-2 fill; hover adds an accent-weight underline inside the frame and darkens the wash by one step; active swaps the frame and the label to oxblood over an oxblood wash; solid is reserved for the one committing action on a surface; disabled loses its fill and keeps a dotted frame. The frame weight never changes — only its colour — so nothing jumps by a pixel when you point at it.

Interaction language, summarised
StateSignal
Hoverone step darker wash, frame colour → --rule-2, label → --ink; on text-first targets the label goes italic and picks up an accent underline
Presstwo steps darker wash, frame → --ink-3
Active / onoxblood frame + oxblood wash + oxblood label at 600, or an ink-blue set for “connected to something out there”
Selected (keyboard)selection ground + a 2px oxblood change bar on the left edge
Focused (workspace, window)corner ticks plus an ink-blue 1px frame; the ring travels between cells in 160 ms
Busythe status line goes Pagella italic; no spinners anywhere
Failurethe affected rule and text turn oxblood; the sheet does not change colour
Disabled--ink-4 text, dotted hairline, no fill
