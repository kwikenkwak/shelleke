New-worktree dialog

A centred modal on the focused screen over the same 82%% scrim as the session screen, keyboard-exclusive so the name field is typeable the moment it appears; Escape or a scrim click closes it. The dialog is 440 px wide with a 3 px border, 14 px padding and 10 px gaps, capped at 900 px tall.

Sections: NEW WORKTREE title + ESC button; TASK NAME field (validated against [A-Za-z0-9._-]+); REPOS — one bordered row per discovered repo with a filled/hollow 22×22 checkbox, the repo name, a server count, and (when ticked) a 3-column grid of server chips; a heads-up listing repos that need jj git init --colocate; a SUMMARY key/value grid (PATH / BOOKMARK / ENV / SETUP / TABS) computed live from the selection; CREATE (fills the width, reads "WORKING…" while busy) + CANCEL; a REOPEN list of existing task folders as full-width fill-on-hover rows; and a scrolling log box whose border turns to plain fg on failure.

Font note: the shell renders body text in Tiny5 (bitmap, PixTheme.fontMainChoice = "tiny5") and titles in Silkscreen, both bundled in assets/fonts/. These pages use a system monospace fallback stack, so glyph shapes differ — metrics, sizes, weights, spacing and colors are the real values.
