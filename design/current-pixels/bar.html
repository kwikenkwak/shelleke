Bar & bar popups

The top bar: a full-width, 46 px tall PanelWindow anchored top/left/right on every screen, reserving 46 px of exclusive zone. Background is bg; the only chrome is a 3 px bottom border in line. Content is inset 12 px left/right and sits above the border. Scrolling the left half changes brightness, the right half changes volume (both raise the OSD).

Left tray icons → divider → RAM / CPU / Claude stats → divider + now-playing title. Center ten workspace cells. Right clock → divider → screenshot, dark-mode, battery chip.

Font note: the shell renders body text in Tiny5 (bitmap, PixTheme.fontMainChoice = "tiny5") and titles in Silkscreen, both bundled in assets/fonts/. These pages use a system monospace fallback stack, so glyph shapes differ — metrics, sizes, weights, spacing and colors are the real values.
