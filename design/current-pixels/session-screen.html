Session / power screen

A full-screen, keyboard-exclusive overlay on the focused screen over a scrim of bg at 82%% opacity (86%% in light mode). Centred column, 26 px gaps: the word SESSION in Silkscreen 24, a row of six 132×132 tiles (3 px borders, 18 px apart), a hint line, then any session warnings as filled chips.

Each tile is a number accelerator in the top-left corner (grey until selected), a 42 px pixel glyph and a Silkscreen label. The selected tile is fully inverted. Arrows/Tab move the selection, hover selects, Enter or Space runs it, 1–6 jump and run immediately, Escape or a scrim click cancels. Unselected tiles get an opaque bg backing so the scrim never bleeds through.

Font note: the shell renders body text in Tiny5 (bitmap, PixTheme.fontMainChoice = "tiny5") and titles in Silkscreen, both bundled in assets/fonts/. These pages use a system monospace fallback stack, so glyph shapes differ — metrics, sizes, weights, spacing and colors are the real values.
