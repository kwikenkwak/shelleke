Displays overlay (hyprdynamicmonitors)

A 380 px panel anchored top+left+bottom (full screen height), 3 px border, 12 px padding, 10 px gaps — a GUI for hyprdynamicmonitors. Opened by keybind / IPC, closed by click-out or Escape. It is a three-screen stack: main (quick layout, connected monitors, profiles), and two full-panel overlays — the profile editor and HDM settings — each entered with a back chevron.

Main, top to bottom: DISPLAYS title + refresh + gear; a daemon square (filled = running) with the active quick mode / profile on the right; a scrollable body with QUICK LAYOUT (Extend / Mirror / Single, then arrangement, primary screen and per-screen zoom chips), CONNECTED cards (filled square = output enabled, then name · description and WxH@Hz  x,y  scale), and the PROFILES list (filled marker = the one HDM has active, 45%% opacity when disabled); a status line at the bottom.

Font note: the shell renders body text in Tiny5 (bitmap, PixTheme.fontMainChoice = "tiny5") and titles in Silkscreen, both bundled in assets/fonts/. These pages use a system monospace fallback stack, so glyph shapes differ — metrics, sizes, weights, spacing and colors are the real values.
